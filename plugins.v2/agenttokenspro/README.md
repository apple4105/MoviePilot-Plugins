# Agent Tokens Pro

管理多平台 Token 配额，按优先级自动切换 Agent LLM 供应商。

## 致谢

本插件基于 [jxxghp/MoviePilot-Plugins](https://github.com/jxxghp/MoviePilot-Plugins) 的 `AgentTokens` 插件进行二次开发，感谢原作者的贡献。

## 主要增强功能

- **失败自动切换通知**：供应商连续失败达到阈值时自动跳过，并发送系统通知
- **两阶段连通性测试**：GET /models 验证鉴权 + POST chat/completions 验证对话兼容性
- **硬故障分级**：401/402/403/404/429 等致命错误标记 `hard_disabled` 永久禁用，瞬时故障自动冷却恢复
- **硬故障踢出**：HTTP >= 400 错误直接标记硬故障，踢出活跃供应商并触发切换
- **厂商管理**：支持厂商（Vendor）维度管理 API 地址，供应商引用厂商配置
- **Dashboard 故障高亮**：故障供应商名称标红，未配置供应商名称标黄，硬禁用供应商红色标签
- **流式连通性测试高容错读取**：自动过滤 SSE 心跳行，支持非 UTF-8 响应
- **取消任务保护**：用户取消任务不触发供应商故障计数和切换
- **未保存更改保护**：配置有改动时手动刷新会弹确认弹窗，避免误丢修改；刷新后 Toast 提示「配置已重新加载」
- **活跃供应商置顶**：配置表与用量表视图层自动将当前活跃供应商置顶，便于定位
- **冷却倒计时**：前端实时展示故障供应商的冷却剩余时间，到期自动恢复参与选择
- **全局设置同步**：通过 `_sync_global_settings` 将当前供应商回写到全局配置，使不经事件链的系统功能（如 ActivityLogMiddleware 摘要）也能使用插件供应商
